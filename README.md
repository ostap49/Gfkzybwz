# Rozkladka

Безкоштовний помічник набору для **Windows 10/11**, натхненний [Klavko](https://github.com/stepsergius/Klavko) для macOS (код Klavko не використовується — це окрема реалізація на C#/.NET).

Rozkladka сама виправляє слово, набране не в тій розкладці: `ghbdsn` → `привіт`, `руддщ` → `hello`. Усе працює локально, текст нікуди не надсилається.

## Що вже вміє (v0.1, MVP)

| Можливість | Як |
|---|---|
| Автозаміна слова в неправильній розкладці | після пробілу, Enter або Tab; `ghbdsn?` → `привіт,` |
| Скасувати заміну | **Backspace** одразу після неї |
| Змінити розкладку слова вручну | **⇧⇧** (двічі Shift) — поточне або щойно набране слово; повторно — назад |
| Змінити розкладку виділеного тексту | **Pause** |
| Винятки | двічі скасували заміну того самого слова → воно саме потрапляє у винятки |
| Вимкнення в програмах | термінали, редактори коду, менеджери паролів — за замовчуванням; будь-яку програму — з меню |
| Індикатор розкладки | іконка в треї (UA / EN …), лівий клік — увімкнути/вимкнути автоперемикання |
| Автозапуск з Windows | пункт меню |

Будь-які дві й більше розкладок Windows: слово перевіряється словником Windows (Spell Checking API) для кожної мови, обирається та, де воно справжнє. Якщо словника для мови немає — працює обережна евристика (лише явне «сміття» на кшталт `ghbdsn`). Слова з цифрами, слова, які ви редагували Backspace, і текст з увімкненим Caps Lock не змінюються.

**Словник української.** Якщо Windows не має української перевірки орфографії, покладіть словник Hunspell (`uk_UA.dic` + `uk_UA.aff`, напр. з [LibreOffice dictionaries](https://github.com/LibreOffice/dictionaries/tree/master/uk_UA)) у `%AppData%\Microsoft\Spelling\uk-UA\` і перезапустіть Rozkladka.

## Встановлення

1. Завантажте `Rozkladka.exe` з [Releases](../../releases) (або артефакт `Rozkladka-win-x64` з останньої збірки в Actions).
2. Запустіть — іконка з'явиться в треї. Windows SmartScreen може попередити (програма не підписана): «Докладніше» → «Усе одно запустити».
3. Налаштування: меню іконки → «Винятки й налаштування (файл)…» (`%AppData%\Rozkladka\settings.json`).

## Для розробників

```bash
dotnet test tests/Rozkladka.Core.Tests
dotnet publish src/Rozkladka -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -o publish
```

- `src/Rozkladka.Core` — логіка без Windows API (розкладки, визначення мови, конвертація тексту), покрита тестами; збирається й на Linux/macOS.
- `src/Rozkladka` — трей-застосунок WinForms: низькорівневий хук клавіатури, SendInput, ToUnicodeEx, словники Windows.
- Збірка `.exe` — GitHub Actions (`.github/workflows/build.yml`), тег `v*` створює реліз.

## Дорожня карта (паритет з Klavko)

| Klavko (macOS) | Rozkladka | Стан / готове рішення в Windows |
|---|---|---|
| Перемикання посеред слова (на 3-й літері) | планується | — |
| Виправлення одруків, залиплий Shift (`ПРивіт`) | планується | — |
| Пробіл після коми, `«»`, `—`, `…`, велика літера | планується | — |
| Власні заміни (`сп` → `спасибі`) | планується | — |
| Історія буфера обміну | — | вбудоване **Win+V** |
| Текст з екрана (OCR) | — | **PowerToys → Text Extractor** (Win+Shift+T) |
| Голосовий ввід | можливо (Whisper локально) | вбудоване **Win+H** (перевірте підтримку української у вашій версії) |
| Переклад виділеного | можливо | застосунок DeepL / Google Translate |

## Готові аналоги для Windows

Якщо потрібно «вже й зараз», варто подивитися (перевіряйте підтримку української та джерело завантаження):

- **MySwitcher** — автоматичне й ручне виправлення українська/англійська/російська, локально.
- **Caramba Switcher** — автоперемикання, але орієнтований на російську/англійську.
- **EveryLang** — перемикання + переклад + перевірка орфографії; платний.
- **Mahou** — відкритий код, ручна конвертація останнього слова/виділення, без автоматики.
- **CCaps** — перемикання розкладки клавішею Caps Lock, підтримує українську.
- Punto Switcher — від Яндекса; не рекомендовано.

Програми такого типу перехоплюють клавіатуру (як кейлогер), тож антивірус може їх позначати — довіряйте лише тим, джерелу яких довіряєте.
