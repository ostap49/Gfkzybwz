# Сторінка в Microsoft Store — чернетка

## Назва
Rozkladka — автоперемикач розкладки

## Короткий опис (до 100 символів, показується в пошуку)
Пишете «ghbdsn» замість «привіт»? Rozkladka сама виправить розкладку. Безкоштовно й без інтернету.

## Опис
Rozkladka автоматично виправляє слова, набрані не в тій розкладці клавіатури: ghbdsn → привіт, руддщ → hello.

• Автоматично: слово виправляється після пробілу, Enter чи Tab, а розкладка перемикається сама.
• Скасування: Backspace одразу після заміни повертає як було. Слово, яке ви двічі повернули, більше не змінюється.
• Вручну: двічі Shift — змінити розкладку поточного слова; Pause — виділеного тексту.
• Розумно: слова перевіряються словниками Windows, тож справжні слова й одруки не чіпаються.
• Безпечно: вимкнено в терміналах, редакторах коду й менеджерах паролів; будь-яку програму можна виключити.
• Приватно: без облікових записів, реклами й інтернету — набраний текст не залишає комп'ютер.

Працює з будь-якими розкладками Windows: українська, англійська, польська, німецька та інші.

## Що підготувати
- Скриншоти 1366×768 або більші (мінімум 1): трей-меню, приклад «ghbdsn → привіт», налаштування.
- Політика конфіденційності: посилання на `docs/privacy.md` (репозиторій має бути публічним або сторінку розмістіть на GitHub Pages).
- Обґрунтування для `runFullTrust` (поле «Submission options → Restricted capabilities»):
  > The app is a keyboard layout corrector. It needs a low-level keyboard hook to detect words typed in the wrong layout and SendInput to retype them in the correct layout, which requires a full-trust desktop process. Typed text is processed locally in memory only and is never stored or transmitted.
- Вікові рейтинги: анкета IARC — «утиліта», без контенту.
